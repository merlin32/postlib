# PostLib

PostLib is a dedicated web site where users can sell their wallpapers and ringtones.

## Description

This project is a platform designed for digital assets, specifically high-quality wallpapers (such as cars, aviation/planes, and various backgrounds) and ringtones (such as underground and trap beats). It is built using Node.js, Express.js for the backend server, EJS for templating, and Sass for styling. It also utilizes PostgreSQL (`pg`) for the database and `sharp` for image processing.

## Initialization

To initialize and run this project locally, you need to install the required dependencies. 

Since the project includes a `package.json` file, you can install all dependencies by running:

```bash
npm install
```

If you are looking for the original manual initialization steps, the following commands were used:

```bash
npm init
npm install express
npm install ejs
npm install -g nodemon
npm install sass
```
*(Note: additional dependencies like `pg`, `sharp`, and `bootstrap` are also required and are included in the `package.json`)*
